# 粒子之间

大厅离线发行入口为 `web-dist/index.html`，运行 `npm run build` 可从 `dist/` 重新生成；大厅内导出通过保存桥接，规则文件格式与既有版本兼容。

独立的浏览器粒子模拟器，无依赖、无外部资源。默认 6 类粒子，在「粒子种类数」填入 1–1,024 的整数，按回车或点击别处生效，支持只有 1 种粒子。类型选择和作用矩阵按每页 16 种显示，矩阵可独立切换行页和列页，避免渲染整个大表。随机投放或在画布上按住拖动撒粒子，最多 1,800 颗。

展开「粒子颜色设置」可输入类型编号，选择任意颜色，或点红、橙、黄、绿、青、蓝、紫按钮。自动配色在 7 种时使用这七种基本颜色，超过 7 种时按种类数细分整个彩虹色环，无需扩充固定颜色表。点击「全部恢复自动配色」取消手动覆盖。更改种类数时保留现有编号的手动配色，自动颜色会重新细分。类型编号显示为 A～Z、AA、AB 等。

在作用矩阵下勾选「仅从列表中随机」，填写候选系数（例如 `-1, -0.5, 0, 0.5, 1`），点击「随机规则」后每个系数只从这些数字中等概率抽取。支持逗号、中文逗号、空格、换行分隔，重复数字会去重，每个数字须在 −1～1 之间（含边界）。允许列表只有一个数字或只有零；不会对候选数额外四舍五入。修改列表不会改变已有矩阵，增加种类时新产生的系数也遵守列表。空列表、非数字或越界值会提示，且不改动现有矩阵。候选列表和开关会一起保存、导出与读取，旧收藏仍可使用。

画布下方可手动「前进 1 帧」「前进 1 秒」或输入 N 后「前进 N 帧」（1–3,600 帧）。按每秒 60 个物理帧精确推进，不受演化速度倍率影响，结束后保持暂停。较大的 N 分批计算并显示进度，可点「停止推进」停在已完成的帧数；推进过程中暂时锁定规则和投放操作。

「运行速度」直接填写每秒演化帧数（1–600），默认 60，可选择慢速 30、正常 60、快速 120。数值小于 60 是慢放，大于 60 是快放；物理步长固定，因此调速不会改变同样帧数后的运动结果。手动「前进 1 秒」仍推进 60 个物理帧。右上角显示的是画面刷新帧率，与设定的演化速度分别计数。高速度受设备性能和粒子数量影响，计算分批进行，限制积压以保持界面可操作。

收藏仍使用原来的 speed 倍率字段（帧率除以 60），因此已保存的旧版规则及 JSON 文件继续可读，例如旧版 0.7× 会显示 42 帧/秒。

在「我的规则」中输入名称，点击「保存当前」收藏整张矩阵、粒子种类、双向开关、作用距离、强度、速度和轨迹开关。关闭后用同一浏览器打开同一文件，选择收藏并点击「读取」即可恢复。保存的是规则，不含粒子位置。每次保存新增一份收藏，不覆盖旧规则。

每种粒子的手动颜色也会随规则保存、导出和恢复。大矩阵的规则文件允许导入至 64 MB；浏览器本地收藏受其存储配额限制，空间不足会保留原收藏并提示导出文件备份。

收藏保存在浏览器本地；「导出所选」将收藏导出为 JSON，未选择收藏时为「导出当前」。「导入」把文件加入收藏，随后点击「读取」。移动离线 HTML 文件、换浏览器或清理存储前，可先导出备份。存储不可用时会提示，并仍可导出当前规则。损坏的规则库不会被自动覆盖。

作用矩阵以行为受力粒子、列为影响它的粒子。系数 −1～1：负数排斥（红），正数吸引（绿），零没有作用（纯黑）；颜色随绝对值连续变暗。两个方向可独立设置，也可以启用双向相同。粒子类别颜色独立于矩阵颜色。无额外的隐式排斥力；零系数严格不产生作用力。粒子有速度阻尼，边界相连。

直接双击 `粒子之间.html`，即可离线运行。用 `node build-offline.mjs` 根据 dist 源文件重新生成离线版。

`node server.mjs` 启动 http://127.0.0.1:4186 。静态部署目录为 `dist`。

`npm test` 检查力的方向、零系数、有向规则、周期边界、小网格去重、色标和数量限制。

`node tests/browser.cjs` 使用本机已有 Playwright 与 Chrome 验证交互和手机布局，截图在忽略的 evidence 目录。该验证脚本的依赖路径针对当前工作区。

`node tests/rules-browser.cjs` 在生成的离线文件上验证收藏持久化、参数还原、导出导入、损坏数据保护及手机布局。
